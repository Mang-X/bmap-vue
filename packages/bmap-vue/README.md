# bmap-vue

Vue 3 components and hooks for Baidu Maps JavaScript API 4.0.

This package is published as `bmap-vue` and follows the 1.0 release line. It began as [yue1123/vue3-baidu-map-gl](https://github.com/yue1123/vue3-baidu-map-gl); see the repository [README](https://github.com/Mang-X/bmap-vue#readme), [NOTICE](https://github.com/Mang-X/bmap-vue/blob/main/NOTICE.md), and [LICENSE](https://github.com/Mang-X/bmap-vue/blob/main/LICENSE) for the project history and attribution.
